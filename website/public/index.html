Agent Screen
Install GitHub

Give each AI agent its own Mac screen.

Claude Code or Codex opens apps, clicks and types on a virtual display, while your cursor, keyboard and windows stay yours.

Download for macOS Install with Homebrew

macOS 15 or later. Open source under the MIT license.

Keep working while the agent works.

Built-in computer use drives your real mouse and keyboard, so you stop working while the agent works. Agent Screen moves the agent onto a display of its own. You watch it from the menu bar, step in when it asks, and hand the screen back with one click.

The agent works on its own display

The Viewer shows the agent's display live. Your pointer, keyboard and windows stay where they are.

It asks when it needs you

An agent stuck on a login or a captcha asks for you with a card under the menu bar icon and a notification, then waits.

You take the wheel, then hand it back

Your first click, scroll or key press in the Viewer, or Take Over, pauses the agent. Its input tools fail until you press Let … Continue.

One display per agent session.

Run three agents at once and each gets its own screen. Subagents of one session share theirs. Your windows never move.

Three of the twelve scripted sessions in the repo's fleet test, sped up 8×.

Peek

Hover the menu bar icon to see every agent's screen live.

Handover

Drag one of your windows onto an agent's screen to give it the window, and take it back with Take Back.

Menus and controls through accessibility

Agents press buttons and pick menu items by name, so a button still gets pressed after its window moves or resizes.

Install

  1. Install with Homebrew

    It needs macOS 15 or later.

    Terminal
    brew tap fanzzzd/agent-screen
brew trust fanzzzd/agent-screen
brew install --cask agent-screen

    Homebrew loads casks from a tap outside its own only once you trust it, which brew trust does.

    Or download the DMG from the latest release and drag Agent Screen into Applications. Agent Screen is signed with a Developer ID and notarized by Apple, so it opens like any downloaded app.

  2. Open Agent Screen

    The setup window asks for Screen & System Audio Recording and Accessibility. Both stay on this Mac.

  3. Connect your agents

    Press Connect… in the setup window, or right-click the menu bar icon and choose Connect Claude Code and Codex, or run:

    Terminal
    "/Applications/Agent Screen.app/Contents/MacOS/AgentScreen" mcp install

    This registers the MCP server with Claude Code for all projects and adds it to ~/.codex/config.toml. For any other MCP client, add a stdio server with the command /Applications/Agent Screen.app/Contents/MacOS/AgentScreen and the argument mcp.

Then start a new session and ask your agent something like:

Use Agent Screen to open Calculator on your own display and work out 12 × 34.

Privacy

Agent Screen runs on your Mac and sends nothing anywhere. Agents reach it through a socket only your user account can open, and a session can only see and drive its own display.

Limits

  • It uses private macOS APIs, so it can't be in the App Store, and a future macOS may break it.
  • Copy, paste and undo shortcuts do nothing in an app on an agent's display. Agents copy and paste through the accessibility tree instead.
  • Canvas apps and games that filter per-process events may ignore forwarded input.

The README lists every known limit.
