Agent Screen / Claude Code on macOS

Let Claude Code use your Mac without taking your mouse.

When Claude Code drives a GUI app with built-in computer use or AppleScript, it moves your real cursor and steals window focus. Agent Screen gives each Claude Code session its own virtual display on macOS 15 or later, so it clicks and types in the background while you keep working.

macOS 15 (Sequoia) or later Free, MIT licensed Works with Claude Code, Codex, and other MCP clients

1. Install and connect Claude Code

Agent Screen is a free, Apple-notarized macOS menu bar app. Install it with Homebrew or download the DMG from GitHub Releases.

Homebrew
brew tap fanzzzd/agent-screenbrew trust fanzzzd/agent-screenbrew install --cask agent-screen

Open Agent Screen and grant Screen & System Audio Recording and Accessibility in its Settings window. Both permissions stay on your Mac; Agent Screen sends no telemetry.

Then press Connect… in Settings, or run one command in Terminal:

Register MCP server + skill for Claude Code
"/Applications/Agent Screen.app/Contents/MacOS/AgentScreen" mcp install

This registers the agent-screen stdio MCP server with Claude Code for all projects (equivalent to claude mcp add --scope user) and writes the Agent Screen skill to ~/.claude/skills/agent-screen. Start a new Claude Code session so it loads the new MCP server, then verify with claude mcp get agent-screen.

Test it with a simple prompt:

Use Agent Screen to open Calculator on your own display and work out 12 × 34.

2. Why the Agent Screen skill matters for Claude Code

Claude Code loads MCP tools lazily when it searches for them. Without a skill telling it when a task needs a screen, Claude Code frequently runs open -a or AppleScript, which pops windows onto your own desktop and takes focus.

The Agent Screen skill teaches Claude Code to call create_display and launch_app whenever a task involves opening, operating, testing, or screenshotting a Mac app or web page. AgentScreen mcp install installs and updates that skill automatically with each app update.

If you prefer managing the skill as a Claude Code plugin directly from GitHub, install it instead (when the plugin is present, mcp install writes no duplicate copy):

Optional: Claude Code plugin
claude plugin install agent-screen --marketplace Fanzzzd/agent-screen

On Claude Code versions before 2.1.292, run claude plugin marketplace add Fanzzzd/agent-screen first, then claude plugin install agent-screen@agent-screen.

3. Watch, step in, and hand windows over

Because Claude Code works on an off-screen virtual display, Agent Screen gives you four controls from the menu bar so you stay in charge without giving up your cursor:

  • Peek and Web Preview: Hover the menu bar icon to see every active Agent Display live, or click it to pin Peek. Each display also gets a local read-only preview_url on 127.0.0.1 that Claude Code can paste into chat.
  • Help Request: When Claude Code reaches a sign-in page, 2FA prompt, or captcha, it calls request_help. A Help Card drops under the menu bar icon with the display picture and reason. Answer with Take Over, Continue, Reply, or Give a Window.
  • Takeover: Click into the Viewer at any time to drive the display directly. Agent Screen refuses all agent input during a Takeover until you press Let … Continue or explicitly tell Claude Code to continue in chat.
  • Handover: Need Claude Code to inspect a browser tab or Mac app you already have logged in? Drag your window onto the Viewer or pick it under Give. When the session finishes, Agent Screen returns the window to where it came from.

4. Running several Claude Code sessions at once

Claude Code passes CLAUDE_CODE_SESSION_ID to its stdio MCP servers. Agent Screen reads that identifier so parallel Claude Code conversations each receive an isolated Agent Display instead of stepping on each other's windows.

Subagents spawned inside one Claude Code conversation share that conversation's display. If a single task needs two apps side by side, the session can call create_display with new: true for up to four labeled displays at once. Running many displays simultaneously? Enable Smooth Display Changes in Settings (see how ColorSync cleanup works).

5. What it does not do

Not a security sandbox. Claude Code drives real apps on your Mac under your user account. If you want full OS isolation for untrusted tasks, run a macOS virtual machine instead.

  • Private macOS APIs: Background input uses SkyLight and CGVirtualDisplay, so the app cannot be on the Mac App Store and future macOS updates may break it.
  • Copy, paste, and undo shortcuts: macOS routes ⌘C, ⌘V, and ⌘Z to the focused app, so they do nothing on a background display. Claude Code uses act_on_element (read_text / insert_text) through the accessibility tree instead.
  • System drags and stubborn clicks: Cross-window drags (such as dragging a file from Finder into a browser) and certain Electron menu clicks wait in the visible Input Queue. Nothing touches your real mouse until you press Allow, and moving your mouse immediately revokes it.
  • Shared browser typing: If Claude Code opens a window in a browser you are actively typing in, Agent Screen holds your keystrokes briefly while the window opens and uses accessibility actions so the agent's clicks do not steal your typing focus.

6. Frequently asked questions

Why does Claude Code need the Agent Screen skill in addition to the MCP server?

Claude Code loads MCP tools only when it searches for them. Without the Agent Screen skill, it often falls back to open -a or AppleScript on your own screen. AgentScreen mcp install registers both the MCP server and the skill automatically.

Can two Claude Code sessions run GUI apps at the same time?

Yes. Claude Code passes CLAUDE_CODE_SESSION_ID to its stdio MCP server, so Agent Screen gives each Claude Code session its own Agent Display. Subagents inside one session share that session's display, and a session can request up to four displays at once.

What if Claude Code needs me to sign in or pass a captcha?

Claude Code calls request_help, which drops a Help Card from the menu bar icon and pauses. Click Take Over to sign in inside the Viewer, then press Let Claude Code Continue or tell it in chat to resume.
