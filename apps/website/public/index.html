Peek

Every Agent Display, one hover away.

Hover the menu bar icon to see every Agent Display live, or click it to keep Peek up. Open any of them in the Viewer to watch it full size.

Help Request and Takeover

It asks when it's stuck. You take the wheel.

An agent stuck on a login or a captcha asks for you with a card under the menu bar icon and a notification, then waits. Take Over pauses it. To hand the display back, press Let … Continue or tell the agent to continue in the conversation.

Handover

Hand a window over. Take it back.

Drag one of your windows onto the Viewer, or tell the agent to take it in the conversation. Press Take Back or ask the agent to return it, and the window goes back to where it was. An agent can also ask for a window; you answer Hand Over or Keep.

One display per agent session.

Run three agents at once and each gets its own screen. Subagents of one session share theirs. Your windows stay put unless you give them to an agent. With many displays, turn on Smooth Display Changes in Settings.

  • Menus and controls through accessibility

    Agents press buttons and pick menu items by name, so a button still gets pressed after its window moves or resizes. They pick an item in a pop-up or a web page's select without opening its menu, and step sliders without dragging.

  • Input Queue

    When background input can't do a web drag or a click, the agent asks to use your pointer. A card shows what it wants to do, and nothing runs until you press Allow. Move the mouse, press a key or press Stop to take it back.

  • Agent Pointer

    The Viewer and Peek draw an arrow where the agent last acted. Agent screenshots don't contain it.

  • Recording

    An agent can record its display to an MP4, with the sound of its apps and a timeline of its actions and your Takeovers.

Install

  1. Install with Homebrew

    It needs macOS 15 or later.

    Terminal
    brew tap fanzzzd/agent-screenbrew trust fanzzzd/agent-screenbrew install --cask agent-screen

    Homebrew loads casks from a tap outside its own only once you trust it, which brew trust does.

    Or download the DMG from the latest release and drag Agent Screen into Applications. Agent Screen is signed with a Developer ID and notarized by Apple, so it opens like any downloaded app.

    Agent Screen updates itself. It downloads new versions in the background and installs them once no Agent Display is open, so an update never ends an agent's work.

  2. Open Agent Screen

    Agent Screen's Settings window asks for Screen & System Audio Recording and Accessibility. Both stay on this Mac.

  3. Connect your agents

    Press Connect… in Settings (right-click the menu bar icon and choose Settings…), or run:

    Terminal
    "/Applications/Agent Screen.app/Contents/MacOS/AgentScreen" mcp install

    This registers the MCP server with Claude Code for all projects and adds it to ~/.codex/config.toml. For any other MCP client, such as Gemini CLI or OpenCode, add a stdio server with the command /Applications/Agent Screen.app/Contents/MacOS/AgentScreen and the argument mcp.

  4. Ask for something

    Start a new session and ask your agent something like:

    Use Agent Screen to open Calculator on your own display and work out 12 × 34.

Privacy

Agent Screen runs on your Mac and sends nothing anywhere. Agents reach it through a socket only your user account can open, and a session can only see and drive its own display.

Limits

  • It uses private macOS APIs, so it can't be in the App Store, and a future macOS may break it.
  • Copy, paste and undo shortcuts do nothing in an app on an agent's display. Agents copy and paste through the accessibility tree instead.
  • Canvas apps and games that filter per-process events may ignore forwarded input.
  • A web drag with no background route waits in the Input Queue until you press Allow, then uses your pointer.

The README lists every known limit.
