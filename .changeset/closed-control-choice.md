Agents can choose an item in a pop-up button or a web page's select, such as a country or birth date field, with `act_on_element set_value` and the item's exact title (#79). No menu opens, so your keyboard stays yours. In a Chromium browser or Electron app the agent started with `launch_app`, the page's option is chosen directly, with one change event. Elsewhere Agent Screen types the title into the closed control, sent only to that app, and stops before a key could reach another window or come too late. If the control shows another item, the call fails and says why: an earlier item starting with the same text, a title that differs in case, or a repeated key such as "11", which a web page's select can't take as type-ahead. A control that already shows the title gets no keys. A combo box gets its value and then a confirmation, and the call fails if the app rejects it. A web page's combobox has nothing to confirm, so the call says the text is set but no option is chosen. When you take over the display, the choice stops before the next key and says what the control shows. A text field that reports an error but shows the new value now counts as set.
