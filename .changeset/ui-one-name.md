Each action now has one name in both languages. In Chinese, the menu says 打开 Viewer, 取回 means only taking a window back, 停止 ends your mouse's approval, 撤销授权 revokes window access, Keep Control reads 保持接手, every Not Now reads 暂不, and the recordings window is 录制列表. Before setup is done, the button at the bottom of Settings reads Later (稍后), since it only closes Settings. The mouse card and its notification say "mouse" throughout. A Window Request notification for a window another agent holds no longer names a Keep button the card doesn't show. Chinese text in Settings, cards and notifications now reads as product copy, with “” quotes only, and long Settings rows are shorter.
