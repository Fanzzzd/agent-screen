A link you click in another app while only the agents' copy of Chrome runs now opens in your own Chrome. Before, macOS handed it to the agents' copy and it opened on an Agent Display. Agent Screen closes it there and opens it in your Chrome, starting it if needed. A page an agent opens itself stays where it is, and so does any page that opens without a click or key press of yours, such as a sign-in page an app on an Agent Display opens.
