`request_control` lets an agent ask for its display back while you are operating it. You get a notification and a card under the menu bar icon with its reason, and answer Let … Continue, which hands the display back, or Keep Control, which tells the agent you kept it. Nothing else ends your Takeover: an unanswered request stays open, and the agent can withdraw it. When the agent already has control, the call returns at once.
