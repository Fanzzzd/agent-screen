Agents can drag in web pages of the browser you already use, signed in as you. Add Agent Screen's extension to Chrome, Dia, Arc or Edge from Settings, Your Browser. Before, a drag in a page worked only in a browser the agent started on a fresh profile, without your logins. While an agent drags, the browser shows a bar saying Agent Screen started debugging it; it goes 20 s after the agent's last input, and Cancel on it stops the extension until the browser restarts.
