You can answer an agent's Help Request without taking over its display. The Help Card and its notification now offer Continue, which lets the agent go on, for a step you did yourself, and Reply, which sends the agent what you type, word for word. Give a Window on the card opens the Give menu for that display, and the window you pick answers the request. Take Over works as before: the agent goes on when you hand the display back. The agent is told how you answered, and an agent that withdraws its own request no longer reads that you handed control back. Later now puts off only that request: the agent's next one brings the card back, even with the same reason.
