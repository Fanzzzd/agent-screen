When an agent opens Chrome, Dia or another Chromium browser that you already use, Agent Screen now starts a separate copy of that browser for agents, on its own profile in Agent Screen's support folder. Your browser being in front no longer stops the agents' browser work, and the agents' copy never takes your focus. Drags and selects in its pages work, and a sign-in you do there once stays for later sessions. It has none of your own browser's sign-ins, so an agent that needs your logged-in session still asks you to hand over a window. A browser that allows only one copy still opens agents' windows in your own browser: while you work in one of its windows, they ignore clicks, and the agent is told so and pointed to Chrome for long unattended work.
