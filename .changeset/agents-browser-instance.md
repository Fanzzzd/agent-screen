When an agent opens Google Chrome, Agent Screen now starts a separate copy of Chrome for agents, on its own profile in Agent Screen's support folder, whether or not you use Chrome yourself. Your Chrome being in front no longer stops the agents' browser work, the agents' copy never takes your focus, and agents never use your own profile. Drags and selects in its pages work, and a sign-in you do there once stays for later sessions, shared by all agents. It has none of your own sign-ins, so an agent that needs your logged-in session still asks you to hand over a window. The agents' copy quits once no Agent Display holds its windows, and when Agent Screen quits. If you open Chrome from the Dock, Spotlight, Finder, Launchpad, Raycast or Alfred while your own Chrome isn't running and macOS hands that to the agents' copy, Agent Screen gives the front back and starts your Chrome. When the agents' copy comes forward by itself, Agent Screen only gives the front back. Dia and other Chromium browsers aren't verified for this yet: while you run one, agents' windows still open in your own browser, ignore clicks while you work in one of its windows, and the agent is told so and pointed to Chrome for long unattended work.
