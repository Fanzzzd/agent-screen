# Sidescreen is now Agent Screen

The app has a new name and a website, [agentscreen.app](https://agentscreen.app). It installs as Agent Screen.app from the tap `fanzzzd/agent-screen`: `brew tap fanzzzd/agent-screen && brew install --cask agent-screen`. Agent Displays are named "Agent Screen 1", "Agent Screen 2" and so on, and the agents' MCP server is `agent-screen`.
