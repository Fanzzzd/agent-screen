# The Agent Pointer is a rounded arrow that arcs to each point

The Agent Pointer in the Viewer and Peek is now a rounded arrow in your accent color, in the style of Codex's computer-use cursor. It travels to each point on a curve and leans into the move. On a click it presses in and sends out a ripple. For a few seconds after each action it sways slightly while the agent works out its next step.
