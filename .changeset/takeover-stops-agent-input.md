When you take over an Agent Display, a click, key press or drag the agent sent a moment before no longer lands after you started. The agent hears that you took over and waits for you. Allow and Not Now on the pointer and keyboard request card no longer freeze Agent Screen while the app in front of you is busy. And if macOS briefly stops Agent Screen from seeing a press you started in the Viewer, the app under it gets its release, and your typing no longer waits behind that press.
