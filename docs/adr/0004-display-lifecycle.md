# A display ends in review, and control returns only when handed back

When an Agent Session stops using its display, by `end_display` or a closed connection, the display closes by itself if no window is on it, and otherwise becomes a Review Display that waits for the user. We do not keep every ended display: they piled up in Peek as dimmed "已结束" tiles that users did not understand. We do not close every ended display either: returning windows unasked would move them into the user's workspace mid-task, and the user may still want to look at the result. When the user closes a display the agent is still using, the display ends the same way, and the agent is told the user closed it: stop working on screen and ask before creating another. Without that, the agent read "ended" as a glitch and opened a new display at once. Neither reason is a claim that the task succeeded, because `end_display` and a dropped connection look the same here; the copy says the agent stopped, never that it finished.

A Takeover ends only when the user explicitly hands control back. They can press 让 … 继续 or tell the Agent Session to continue in the conversation. The session relays that instruction through a tool, which uses the same state transition as the button. Agent Screen does not read the conversation or independently verify the instruction; it trusts the session's relay and records it. A request from the agent, silence or a timeout is not a hand-back. Collapsing the Viewer, switching displays or clicking elsewhere used to hand control back, so an agent could resume while the user had only glanced away. Opening the Viewer is watching, not operating: the Viewer takes the keyboard only after a click into the display.

A Takeover also pauses a continuing Window Authorization. Explicitly handing control back resumes it unless it was revoked. An agent cannot use a window authorization to end a Takeover. A Control Request asks for a hand-back without changing control, and remains one request per display; repeating it must not repeatedly notify the user.

A window counts as on a display if it touches the display and its center is on no other display, so a window hanging off an edge is never left behind when the display closes.
