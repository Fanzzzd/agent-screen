# The MCP server runs on upstream Effect v4's McpServer

`packages/mcp` uses `McpServer` from Effect v4 (`effect@4.0.0-rc.118` or later) rather than the official TypeScript SDK. Effect v4 is still a release candidate, but it merged a 2026-07-28 protocol adapter in September 2026 (Effect-TS/effect#7265), so it already speaks the current spec while keeping the whole server in one Effect program. We planned to fork Effect and upgrade its MCP support ourselves; upstream finished that first, so we depend on upstream directly and send fixes there as pull requests. If a bug blocks us before a fix is released, a temporary fork is acceptable.
